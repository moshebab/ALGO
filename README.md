# ALGO — אלגוריתמים (67504) | Lecture Slides

Public lecture slides and interactive simulations for **Algorithms (67504)** at the Hebrew University of Jerusalem.

- **Live Slides Portal**: https://moshebab.github.io/ALGO/

## Updating / Publishing New Lectures

Only published lectures appear on the public `index.html` page.

- **Refresh existing published lectures** after editing slides in `algorithms-course`:
  ```zsh
  ./update_slides.sh
  ```
- **Publish an additional lecture** (e.g., Lecture 09):
  ```zsh
  ./update_slides.sh 09
  ```
